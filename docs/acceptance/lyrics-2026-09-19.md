## Defect found and fixed

The first controlled automatic run exposed an asynchronous shutdown defect in the Windows process-loopback recorder. A completed capture was disposed synchronously while processing was still winding down, causing the result to be discarded before transcription. The recorder now uses asynchronous disposal. The same automatic acceptance sequence then passed all four samples.

## Privacy

The runner stores only a one-way anonymous sample identifier, path classification, outcome, and aggregate alignment evidence. It does not write the title, artist, lyric text, transcript, or captured audio.

## Reproduction

Run a normal source acceptance set:

```powershell
.\scripts\live-lyrics-acceptance.ps1 -Samples 12
```

For a controlled automatic-path run, start the release build with `--force-plain-lyrics` and run the same script with four or more samples. This switch exists only for acceptance coverage and does not change normal application startup.
