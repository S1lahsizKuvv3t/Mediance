# Support

GitHub Issues is the main support channel during the public beta.

Before opening an issue:

1. Check the [FAQ](FAQ.md).
2. Follow the relevant steps in [Troubleshooting](TROUBLESHOOTING.md).
3. Search existing issues for the same behavior.

Use the bug-report form when something does not work and the feature-request form for a new idea. One issue should describe one problem.

A useful bug report includes the Windows version, display scale, media application, steps to reproduce, expected result, actual result, and whether the problem happens every time. Song names, lyrics, account information, and screenshots containing private information are not required.

Security vulnerabilities should follow [SECURITY.md](../SECURITY.md) and should not be posted publicly.
