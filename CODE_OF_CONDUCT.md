# Community guidelines

Mediance welcomes bug reports, ideas, testing notes, documentation fixes, and code contributions from people with different levels of experience.

Be direct about technical disagreements without making them personal. Give enough context for someone else to reproduce a problem, assume honest mistakes, and leave room for a contributor to revise their work. Harassment, threats, discriminatory language, publishing private information, and repeated disruption are not accepted.

Project maintainers may edit or remove comments, issues, pull requests, or other contributions that do not follow these guidelines. Serious or repeated violations may result in temporary or permanent restrictions from project spaces.

If a conduct concern includes sensitive information, use a private repository contact method rather than a public issue.
